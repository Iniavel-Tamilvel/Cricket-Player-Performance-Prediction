# Cricket Player Performance Prediction

A machine-learning portfolio project estimating a batter's expected runs from player, venue and recent-form features.

**Workflow:** data quality → EDA → feature analysis → Linear Regression vs Random Forest → 5-fold cross-validation → evaluation → feature importance.

**Important:** the included dataset is synthetic and intentionally small. Replace it with a properly licensed historical dataset before making real-world claims.

## Run
```bash
pip install -r requirements.txt
python notebooks/cricket_analysis.py
```
